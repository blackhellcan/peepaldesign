How to add it to Figma
  1. First time only: download the GapScan Importer plugin and unzip it. In the Figma desktop app, choose Plugins → Development → Import plugin from manifest… and pick manifest.json.
  2. Open the Figma file you want, run Plugins → Development → GapScan Importer, and choose the file you downloaded.

GapScan never changes a Figma file itself; the plugin does, inside Figma, when you run it.
